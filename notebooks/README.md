# Notebooks

- `01_explore_data.ipynb` — exploratory analysis of the two raw datasets
  (`data/raw/Resume.csv.gz`, `data/raw/job_resume_fit.csv.gz`): shapes, category
  balance, score distributions and parsing of the stringified skill lists.

Run from the repository root (or from `notebooks/`) with the dev dependencies
installed (`pip install -r requirements-dev.txt jupyter`).
